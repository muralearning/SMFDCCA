# ρSMFDCCA

This repository accompanies the baseline **ρSMFDCCA** paper. It contains the mathematically frozen Python implementation of the signed multifractal detrended cross-correlation coefficient, alongside utilities for reproducible publication formatting, plotting, and numerical validation.

## Overview

ρSMFDCCA is a coefficient designed to quantify the cross-correlation between two non-stationary time series across multiple timescales and fluctuation orders, maintaining information about the sign of the correlation.

This v1.0 release is explicitly focused on providing a stable, mathematically frozen, and reproducible baseline implementation.

## Installation

```bash
git clone https://github.com/rhoSMFDCCA/rhoSMFDCCA.git
cd rhoSMFDCCA
pip install -r requirements.txt
```

## Quick Start

The core algorithm is provided in `smfdcca.py`. You can integrate it directly into your pipelines without using the included plotting or export utilities. 

Unless explicitly specified otherwise by the user, the default detrending polynomial order is `m = 1` (`pol_ord=1`) across all public entry points.

```python
from smfdcca import mfdcca_coefficient

# x, y: 1D arrays of time series data
# windows: list of window sizes (e.g., [13, 21, 34, ...])
# q_values: list of fluctuation orders (e.g., [-2, 0, 2])

results = mfdcca_coefficient(x, y, windows=windows, q_values=q_values, pol_ord=1)
```

## CSV Output Description

For publication purposes, we strictly use a standard 3-column CSV output:

```text
window,q,rho
```

This format is guaranteed to remain stable and is generated by the `export.py` module. 

## Reproducing Manuscript Examples

The repository includes reproducible examples directly mirroring the manuscript. To execute the financial and weather examples, you must supply the datasets.

**Note**: The implementation explicitly avoids falling back to synthetic data if the real datasets are missing. If the datasets are not located in the `data/` directory, execution will halt with a clear error message.

### Independent Random Signals
Does not require external data.
```bash
python examples/example_random.py
```

### Dow Jones × NASDAQ
Requires `DJI.csv` and `IXIC.csv` inside the `data/` directory.
```bash
python examples/example_financial.py
```

### Weather Datasets (São Paulo)
Requires `Temp_Mean_daily_SP.csv`, `Humid_Mean_daily_SP.csv`, `Temp_Max_daily_SP.csv`, and `Temp_Min_daily_SP.csv` inside the `data/` directory.

This example computes two complementary analyses for São Paulo:
- Mean Temperature × Mean Relative Humidity
- Maximum Temperature × Minimum Temperature

```bash
python examples/example_weather.py
```

## Figure Generation

All plots generated by this repository are manuscript-ready scatter plots without significance formatting. They are automatically produced when running the examples in `examples/`, saving `PNG (600 dpi)`, `PDF`, and `SVG` files directly to the `figures/` directory.

To manually plot a standardized CSV:

```bash
python plotting.py data/your_exported_data.csv
```
